# Bejeweled 3 Six Card — 源码整理候选

针对固定 Windows x86 Bejeweled 3 构建的六张牌扩展，覆盖独立牌局和原版三个任务牌局。采用原版五牌存储与扩展侧第六张、十一种牌型、独立危险阶段及配套统计保存。

本目录是本地开源准备材料，尚未上传。项目许可证未确定，第三方及派生材料出处仍需整理；不能把当前目录视为已完成许可证审阅的公开发行版。

## 目录

- `src/game/`：Beta 1 游戏扩展源码，来自已验收的 Run428。
- `src/launcher/`：Beta 1 干净资料启动器，来自 Run429。
- `src/helper/`：辅助加载器源码，来自 Run363。
- `tests/`：任务规则/模式及危险阶段的 x86 离线检查。
- `docs/TECHNICAL_DRAFT.md`：原理、规则表、格式及验证边界。其中 Run 路径是研究工作区导航，非本目录依赖。
- `docs/SOURCE_ORIGINS.json`：来源路径和原始文件哈希。

## 构建

需要 Visual Studio 2022 的 MSVC v143 x86/x64 工具集及 Windows SDK，使用 Windows PowerShell：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build.ps1
```

脚本构建x86游戏DLL、辅助加载器、启动器，并将此次DLL/加载器哈希写入构建目录的启动器副本。源文件中的Beta身份保留不变。输出在`out/`；离线检查不能替代实机验收。

本目录不包含原版 EXE、游戏资源或存档。若自行组装运行目录，应将你本地对应构建的完整游戏文件放在`out/game/`，保留原版签名配置，不修改`properties/partner.xml`。固定EXE及签名配置的校验值见启动器源码。不要将研究用的解锁资料放入源码或游戏发行目录。

自行构建与Beta原包不保证逐字节相同，尚未对这份重新布局后的源码构建进行实机回归；正式内测包仍以已验收的Beta 1为准。启动器沿用`BJ3SixBeta`资料身份，运行自编译版会使用同一套Beta用户资料，因此本次整理仅构建，不自动启动游戏。
